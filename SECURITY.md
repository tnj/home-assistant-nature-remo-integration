# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting:
<https://github.com/tnj/home-assistant-nature-remo-integration/security/advisories/new>.
Do not open a public issue for security problems.

Your Nature access token grants control of your appliances — never paste it
into issues, logs, or anything you attach.
